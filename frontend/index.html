MediAssist AI

An AI platform for doctors to query patient medical records via a RAG pipeline — reducing consultation time and enabling evidence-based clinical decisions. Features two-portal architecture (patient & doctor), semantic search over uploaded PDFs, and automated consultation note generation.

Architecture

Python backend with FAISS vector store. Documents are chunked, embedded via sentence transformers, indexed in FAISS, and retrieved semantically on doctor queries. An LLM then synthesizes context-aware answers.

Key Features

  • RAG-powered medical Q&A over patient PDF records
  • Patient timeline with chronological document visualization
  • Report comparison (old vs. new diagnostic values)
  • Automated consultation note generation

ShopNest

A production-grade e-commerce platform built on the MVC architecture. Features JWT + bcrypt authentication, admin dashboard with product management, Razorpay payment gateway, Multer image uploads, and MongoDB-backed operations.

Architecture

Express.js server with MongoDB and Mongoose ODM. Routes separated into owners, users, orders, and payments. EJS templates for server-side rendering. JWT handles stateless auth.

Key Features

  • JWT + bcrypt authentication with protected middleware
  • Admin dashboard with CRUD product management
  • Razorpay payment gateway integration
  • Image uploads via Multer · Shopping cart & order tracking
